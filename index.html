Completed

Gesture-Controlled IoT System

A gesture control system using ESP32 microcontrollers, IMU sensing, spectral feature extraction, and MQTT to trigger remote actuator commands.

  • ESP32
  • TinyML
  • MQTT

Highlights

  • ESP32 microcontrollers read hand motion from an IMU sensor.
  • Spectral feature extraction turns raw motion into features a TinyML model can classify on the device.
  • Recognized gestures travel over MQTT to trigger commands on a remote actuator.
